# 岗位分配：选点自动调整

> 历史多轮局部搜索说明：当前手动测试入口已改为一次重插、只对比完整路线，不再调用本文的多轮搜索。最新行为及新接口见 [selected-points-once.md](selected-points-once.md)。

普通岗位方案、独立全点模板的“手动调整测试”新增“选点自动调整”模式。勾选按点位出现次序生成的唯一token，不按设施编号去重，因此保留同一设施多次出现的情况。每趟可选择若干收运点，选择可覆盖多个趟次；只能趟内挪动，起终点及内部卸料锚点固定，未勾选点保持相对顺序。

以点击开始时当前编辑列表为冻结基准，每轮尝试单点搬移、所选点交换、连续所选点的两点/三点/整段搬移及选中连续片段反转。整段动作独立于单点是否改善，能发现两个点一起搬移才改善的情况。全部候选比较后选取本轮满足载重、工作时长及应收覆盖要求的最好改善，再进入下一轮；没有改善自然停止。时间窗不筛选候选，也不阻止从更优但超窗的顺序继续迭代。按里程优先（差异不足1米时比较耗时），跳过重复顺序，不设固定轮数、候选数或运行时间上限。这是所选范围局部搜索，不枚举所有排列、不接受临时变差，不保证全局最优。

复用现有道路分段接口和手动对比。搜索阶段只复算完整模板，不运行每日跳点，不检查时间窗；完整模板应收覆盖、载重和同车累计工作时长仍作为筛选条件。搜索结束后，针对最终候选和开始前基准统一检查一次排班周期，生成真实到达和超窗标记、对比场景；每日结果不参与搜索排序，也不重新筛掉或替换已经选定的候选。最终每日载重、工作时长或覆盖检查发现问题时提示并降为黄色，不宣称可执行。道路查询按完整点位顺序缓存；每种新顺序仍由后端按当前路线计算速度，不用固定点对耗时替代密度/转场速度估计。没有新的后端接口或数据库迁移。

当前最佳仅为进度信息，不自动写入编辑列表或主方案；搜索进度显示“时间窗和每日跳点尚未校验”，不能提前显示零冲突或全部通过。最终校验完成后展示开始前基准与候选的地图、里程、耗时和超窗点；更优且时间窗通过为绿色，更优但超窗为黄色。不会优先采用较长但通过时间窗的候选来替代较短超窗候选。可显式采用到编辑列表继续调整，或复用保存替换与方案库另存；超窗替换仍需二次确认。无改善则保留开始前顺序，但仍统一生成原基准的最终问题提示，不对不可行基准宣称可执行认证。“时间窗修正路线”和少量时间窗联合规划保持原有时间窗约束行为。

计算支持AbortController取消，结束或关闭清理计时器。取消/失败不返回或采用部分最佳，保留开始前编辑内容；用户配置或原方案变化仍由现有应用入口拒绝过期替换。进度显示轮数、候选累计数量、正在查询的趟次/日期、当前最佳和运行时间，不使用虚假百分比。

进度分为搜索和最终校验两阶段。搜索展示“正在比较第N个完整模板候选／已完成M个候选”，不显示逐日进度。搜索结束后展示“最终结果统一校验”以及已完成的排班日数量、当前排班日序号和实际第几天；同一周期只执行一遍最终对比，不再每个候选反复从第1天开始。最终校验完成前仍不能采用部分结果，取消时保留开始前编辑内容。

本次仅前端改动，刷新前端即可；后端不需重启。真实岗位数据、地图显示和替换后的导出需另行验收。

按钮按模式隔离：手动拖动模式显示“确定并计算对比”；选点自动调整模式只显示“开始优化所选点”，隐藏普通复算和前移／后移操作。选点模式尚未取得对比结果时禁止保存，不通过保存动作偷偷触发普通复算。点击“采用候选到编辑列表”后自动切回手动拖动模式，保留已计算的对比结果，继续编辑才使对比失效。
